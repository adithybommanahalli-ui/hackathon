# NEXUS SHIELD 🛡️
### Real-Time Cybersecurity & Social Intelligence Platform

A full-stack hackathon demo solving two AI/ML problems simultaneously:
1. **Real-Time Network Intrusion Detection System (IDS)**
2. **Real-Time Public Emotion Intelligence & Crisis Prediction**

---

## Quick Start

### Prerequisites
- Python 3.10+
- Node.js 18+
- pip packages (see `backend/requirements.txt`)

### 1. Install Backend Dependencies
```bash
cd backend
pip install -r requirements.txt
```

### 2. Train the IDS Model
```bash
cd backend
python train_model.py
```
Expected output: **100% accuracy** on synthetic CIC-IDS dataset

### 3. Start Backend
```bash
# Option A: Use the batch script
start_backend.bat

# Option B: Manual
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Backend runs at: http://localhost:8000  
API Docs: http://localhost:8000/docs

### 4. Start Frontend
```bash
# Option A: Use the batch script
start_frontend.bat

# Option B: Manual
cd frontend
npm install
npm run dev
```
Frontend runs at: http://localhost:5173

## ML Models

### IDS Model (Network Intrusion Detection)
- **Algorithm**: RandomForestClassifier (200 trees)
- **Training data**: 10,000 synthetic CIC-IDS-like samples
- **Classes**: BENIGN, DoS, PortScan, BruteForce
- **Accuracy**: 100% on test set
- **Features**: packet_length, flow_duration, packet_rate, byte_rate, flag_count, port_number, protocol, inter_arrival_time

### Emotion Model (Social Intelligence)
- **Model**: `cardiffnlp/twitter-roberta-base-sentiment-latest`
- **Fallback**: Keyword-based heuristic (works without internet)
- **Output**: Positive / Neutral / Angry / Fear percentages

### Fake News Detector
- **Model**: `mrm8488/bert-tiny-finetuned-fake-news`
- **Fallback**: Keyword heuristic
- **Output**: REAL / FAKE per headline + ratio

## Crisis Score Formula

```
crisis_score = (0.40 × network_threat_level +
                0.35 × emotion_anger_level +
                0.25 × fake_news_ratio) × 100

convergence_alert = network_threat_level > 0.7 AND emotion_anger_level > 0.7
```

| Score | Status | Color |
|-------|--------|-------|
| 0–40 | SECURE | 🟢 Green |
| 41–70 | CAUTION | 🟡 Yellow |
| 71–100 | CRITICAL | 🔴 Red |

## Demo Mode

Click **DEMO ON** in the navbar to enable auto-simulation:
- Randomly triggers DoS/PortScan/BruteForce attacks every ~30s
- Randomly spikes social anger levels
- Makes the dashboard look alive for presentations

Click **RESET** to return all metrics to baseline green state.

## Optional: NewsAPI Integration

To use real news headlines instead of samples:
1. Get a free API key at https://newsapi.org
2. Set environment variable: `set NEWSAPI_KEY=your_key_here`
3. Restart the backend
